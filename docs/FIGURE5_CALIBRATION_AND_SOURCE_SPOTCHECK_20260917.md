# Fig.5 定标与历史源抽检

独立检查原 PDF 渲染、原文和粒子点位置后，没有发现能解释近四倍振幅差距的读图定标错误。

- 色条顶部明确写 x10^-2。0.5…3.5 的刻度应读为 .005….035；`figure5_pixel_comparison_20260917.json` 已正确计入。
- 原文 `main_PRL.tex:661` 明确画的是 ell>=2 的绝对值 |phi^(1,1)|，不是场的平方。第285/288行给出物理扰动 epsilon q phi^(1,1)、epsilon=alpha^3 sqrt(Mc/M)。
- 轴标仅为 X、Y，没有 alpha² 的乘子。用原黑色粒子点的像素质心及原刻度独立定位，得到两面板 X=41.59074、41.80517，分别匹配标签41.6M、41.8M，排除把坐标当成 r alpha²/M 的解释。精确的 Kerr 笛卡尔嵌入仍未由原文说明。
- r=100M 的四轴点：上面板 local/paper=3.702…3.871；下面板为4.190…4.362。即使使用原报告的完整 RGB 容差区间，所有八点的比值下限仍大于3.28。色条读数误差不能令其变成1。
- 原场图最亮颜色超出独立色条覆盖，不能把色条最高值当成场全局最大值。本结论仅针对有有效色条匹配的指定点。

定标证据保存在 `docs/environment_reproduction/figure5_digitization_crosscheck_20260917.json`。没有重做全部图像反演。
