# 弱通道的积分条件数与容差检查

仍未解决原图偏差。本报告保持所有源样本、角向投影和两端边界
位置不变，只检验离散求和的相消程度与齐次径向积分精度。

写无穷远振幅为Z=sum_i z_i，其中

\[
z_i=w_i R_{\rm In}(r_i)J(r_i)/\mathcal W_0,\qquad
\kappa=\frac{\sum_i|z_i|}{|\sum_i z_i|}.
\]

若每个离散项的相对误差都不超过delta，则由三角不等式得到
abs(delta Z)/abs(Z)<=kappa delta。这个条件数只描述所给离散和，
不是未知连续源或有限区间之外尾项的误差界。
