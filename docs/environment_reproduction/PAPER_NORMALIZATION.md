# 原论文图间归一化核查

本报告只比较 arXiv:2501.09806v1 的原始矢量图，不使用本项目的求解结果。
数据与 PDF 哈希见 `paper_normalization_audit.json`；重运行入口为
`src/report_paper_normalization.py`（可选依赖 pdfplumber）。

在 alpha=0.3、轨道半径20M，图6中 ell<=6 的模态点相加得到
1.8288422616947143e-5。除以 alpha^6 后得到0.02508699947455027；
图2右侧 Kerr 无穷远曲线的矢量插值为0.025085942621731777。
相对差4.2129e-5。这里只涉及图形取样与插值，并没有严格的数字化误差界。

结合正文 epsilon^2=eta alpha^6，这强烈支持：图6数值按 q^2 eta
归一化，而图2按 q^2 epsilon^2 归一化。该判断是图间闭合关系支持的
推断，不是作者提供的代码约定。此前约1/alpha^6的差异不应全部归为
求解器误差；但当前 scalar(3,3) 与图6仍有约5%的差异，尚未解决。

图2的视界总通量绝对值同点约0.0710065231；它是多个模态之和，
不能与本项目单独的 scalar(0,0) 直接作精度验收。

另外，图4图注写 epsilon^2=0.1 alpha^3，附近正文却指定 eta=0.1。
这与正文 epsilon^2=eta alpha^6 不能同时成立。图4的实际缩放仍需
单独核验，不能用本报告的图2/6闭合关系替代。所有图级验收仍未完成。

## 质量积分测度的独立排查

`report_cloud_mass_measures.py` 从完整逆度规、场梯度和应力张量重新
计算质量，没有调用背景类的质量积分实现。两套径向/角向积分检查
得到 E-omega Q 在 alpha=.2/.3 时分别约 -1.1e-13、-2.3e-12。
将同一个场的测度从 Sigma 改为论文印出的 r^2，并保持正能量符号
与 C=1 不变，单位质量归一化引起的通量乘数分别为
1.000014764504 和 1.000148962161。
所以该测度差别无法解释约5%的 scalar(3,3) 差异。
原文应力张量另有整体因子约定问题，不能只改质量而保留不相容的
能流系数；生产源未作任何经验重标度。完整结果见 `cloud_mass_measures.json`。
