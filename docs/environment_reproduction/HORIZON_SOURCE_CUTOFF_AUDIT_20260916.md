# 主导 scalar00 近视界源截断审查

本轮在当前代码、当前 alpha=0.3、a=0.8771530275949366、轨道半径20 的数据上，计算了遗漏内源区间对复数视界振幅的实际修正。结果不支持数个百分点的 dipole 内源截断误差：将 cutoff 从5e-4降到5e-6，视界轨道能量通量的相对改变量为 **−0.04468%**；两支 Frobenius 外推到视界约为 **−0.04535%**。这是修正数值尾部的实验，没有改变任何通量因子。

## 方法与同一基准

唯一全源基准为 `fresh_20260915_L18_mg-1_sl0.json`，源码依赖及样本校验均通过：

- Z_H = −0.049610141592376984 + 0.03350537620213901 i。
- F_H(00) = −6.700750341090506e-5。
- 原始源为88径向节点、18角向节点，内截断为 r−r+=5e-4。

只在内侧真空区移动源下限。纯规范 dipole 的诱导标量 f 满足同一标量径向方程 Lf=J，因此复数 Green 边界量 B=Delta(R_up f′−R_up′ f)/W 给出

`delta Z_H = B(old cutoff) − B(new cutoff)`。

spin0 与完整 spin1 分别计算后复数求和。负m度规使用正m的复共轭，云本征值及归一化保持不变。轨道项和外端项在两个截断间严格抵消。不是根据源模长估计；相位和两支近视界振荡都保留。

## 结果

以下将新算的 dipole 壳层修正加到同一 fullL18 基准上；不声称其他ell的新壳层也已经算过。

| 新内截断 | delta Z_H | F_new/F_base−1 |
|---|---|---:|
| 2.5e-4 | 2.020367819e-6 − 2.823665658e-6 i | −1.087303812e-4 |
| 5e-5 | 1.276438904e-5 − 4.688520019e-6 i | −4.410103947e-4 |
| 5e-6 | 1.380667494e-5 − 3.456159944e-6 i | −4.468190352e-4 |
| 1.2e-6 | 1.405134754e-5 − 3.451686230e-6 i | −4.535074863e-4 |

两种配置为 complex128/q18 和 clongdouble/q24，均使用诊断积分起点 r+ +1e-7、径向相对容差1e-12。到5e-6时，两配置的 delta Z 绝对差为约2.8e-9，对全通量相对修正的差仅7.64e-8。更内侧抵消误差开始增加，因此不盲目继续降低截断。

外推使用 `B(x)=B0+sum_n[c_n*x^n+d_n*x^(n−2i*gamma)]`，gamma=0.8791718797。扩展精度、具有剩余自由度的三个拟合给出通量相对修正范围[−4.535826792e-4,−4.535198787e-4]，残差约5–7e-9。此范围是经验一致性指标，不是严格误差界。二阶五点拟合具有五个参数，其零残差只是插值，未作为收敛证据。

更严容差2e-13、起点5e-7的独立控制失败于齐次径向积分；已单独保存失败，不纳入收敛结论。

## 实际发现的积分域隐患与最小修复建议

`lorenz_kappa.scalar_resolvent` 当前固定 `offset=1e-4`。`trace_field_jet` 第33行直接调用 `radial.insol.sol(r)` / `radial.upsol.sol(r)`；SciPy会对积分域以外的r静默外推。于是直接把源采样点降低到1e-5，可能根本没有在评估真正求解过的trace/kappa。

本诊断先记录合法旧截断，然后仅在独立进程替换构造器的 offset、清空 resolvent 缓存，延伸实际积分域到1e-7。最低场值采样仍高于云的独立积分起点1e-6。生产数值模块未改。

建议最小改动：在 `trace_field_jet` 获得 radial 后、调用 dense output 前，验证r有限且在闭区间 `[radial.rmin,radial.rmax]` 中，否则抛出明确的 ValueError。trace和kappa都经过此入口，可一起防护。当前5e-4基准在合法域内，不会因此改变数值。

有意义的回归测试是用带调用计数的模拟 resolvent：上下越界和非有限输入应在dense output调用前拒绝；两端点、内外分支的合法点结果保持原值；再经kappa入口检查相同防护。补一个实际参数合法点的复trace/kappa前后对照即可。后续若需要更内采样，应显式传播 horizon offset 参数并纳入缓存键；不要自动换积分起点而不留记录。

## 范围限制

已有fullL18与新近L1 backend样本在最靠内的8个原始节点差异最多为全源的3.78e-4，但这些节点仍位于旧cutoff之外，不能用它证明更内的高ell源已经收敛。完整L18内尾及其重构相消仍没有全量认证。本轮已经直接检验对结果占主导的dipole，未发现可解释原32.7%差异的内端源缺失。

父任务新查到的论文视界归一化更正属于另一条证据，本报告未将该更正混入数值截断实验。此约−0.045%的变化应视作修正参考之后的小残余项。
