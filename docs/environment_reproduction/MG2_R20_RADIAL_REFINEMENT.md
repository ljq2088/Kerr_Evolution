# rp=20M、mg=2的径向加密

11个标量通道均完成，从普通面板8点加密至16点，源节点由88增至144；首个对数面板仍32点、角积分18点、Lg=18及Green边界不变。逐项比较确认仅radial_order改变。数据与输入SHA256见mg2_r20_radial_refinement.json。

主要(3,3)无穷远轨道能流从1.3155145535414752e-5变为1.3155102335424169e-5，相对变化-3.2838854e-6；该变化远小于目前总能流与论文约5%的差异。其余m=3的无穷远分量变化绝对值不超过2.24e-7。

共轭驱动(1,-1)的视界能流从-1.5222259417522308e-8变为-1.522225860108409e-8，相对变化-5.36e-8。然而极小的(11,3)和(11,-1)视界分量分别变化约11.27%和19.90%，不能把主要模态稳定性推广为全部通道收敛。这些量约1e-20，需同时关注绝对幅值与相对变化。

此处没有改变度规截断、角积分或首面板阶数，没有替换标准nr8模态汇总；仅两组径向网格也不能证明整体收敛。
