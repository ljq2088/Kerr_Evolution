# Kerr 与论文偏差：逐模块审核（2026-09-14）

## 当前结论

尚未证实32.66%总视界通量偏差的根因，也没有修改生产方程以追随论文曲线。本轮得到两个新的跨模块检查结果，并确认一个实际数值缺陷：高阶度规重构污染了标量源的连续性和应为零的奇宇称通道。现有量级不足以证明该缺陷解释主偏差。

论文对照点为 alpha=0.3、rp=20M；Kerr a/M=0.8771530275949366。视界偏差+32.6552%，无穷远+5.0454%。Schwarzschild同配置分别约-0.4190%、-0.2818%。这不支持用一个共同归一化常数修正Kerr两端。

## 新检查一：真实标量源在轨道处的连续性

直接计算 J_lm=integral Sigma h^{ab} Hessian_ab S_lm* dOmega；使用正mg=1的完整度规复共轭，云不取共轭，以获得主导scalar m=0的源。rp左右各计算偏移0.001M、0.0005M两点，分别用2J(0.0005)-J(0.001)外推。该二点外推尚无独立收敛误差界。

## 新检查二：主导偶极源积分的独立边界恒等式

L1度规在轨道两侧的真空区是纯规范形式。令相应标量扰动f=-X^a partial_a Phi0；投影后有

    L f = J,    L f = (Delta f')' + V f.

令U是齐次Up解，则

    U J = [Delta (U f' - U' f)]'.

因此在当前有限源区间上，直接积分得到的视界复振幅必须满足

    Z_H = B(r_out)-B(r_in)+B(rp^-)-B(rp^+),
    B(r)=Delta(U f'-U' f)/W0.

最后两项来自分段积分，不能丢弃；它们不是应当额外注入物理标量源的delta函数。对负mg通道，只共轭规范向量，保持复杂背景云不变。

从规范向量及背景云独立构造f、f'，没有调用原来的h:H源积分。使用实际nr16/nt18/L1标量00报告：

- 原视界振幅：-0.05003928027578332 + 0.033703673609542045 i。
- 边界恒等式（轨道偏移0.0005M外推）：-0.050039280295925 + 0.033703673615678574 i。
- 相对复振幅差：3.4900188e-10；对应通量相对变化6.6744121e-10。
- 偏移0.001M时复振幅差2.01e-9，减半后改善。

这是一项跨越规范向量、云导数、源收缩、负m约定和Green积分的检查。但两种路径依然使用同一规范向量输入，因此不能证明该向量与作者采用的物理解相同。

结果与输入哈希：dipole_scalar00_green_identity.json；脚本：src/report_dipole_green_identity.py。

## 论文未公开细节：区分缺失信息与错误假设

1. **两种度规构造流程不同，这是原文明确说明的事实。** 当前辅助源推导依据2406.12510v3。该文引言明确说明：它与2306.16459的方法不同，后者在圆轨道处拼接齐次解，前者避免了椭球到球谐投影。环境论文的方法段说采用Dolan 2023实现，并输出自旋加权球谐数据。两者理论上可能等价，但现有数值验证尚未建立有限截断下的等价性。
2. **不能把“球谐阶18”当作“椭球分离阶18”。** 2023工作公开了特定标架/度规投影及匹配方法；环境论文没有给出其改装包的全部投影、内部截断及精度参数。需要按2023定义重建投影和匹配矩阵，检验到所有保留的球谐阶，而不是对BL坐标分量统一作标量投影。
3. **kappa特解的齐次自由度必须和其他标量规范项一起核对。** 2023附录明确写出Up特解可加齐次Up解。单独比较kappa没有规范不变意义；若改变特解，需要追踪其他齐次幅度的补偿。我们已排除当前kappa有限边界的数值误差，尚未完成这种完整映射。
4. **局部真空方程不是源匹配证明。** h→h-2 nabla_(a X_b)可保留真空Einstein方程；满足适当齐次向量方程的X还可保留Lorenz条件。因此这些局部残差不能单独决定同一个粒子源和边界匹配下的完整度规。要检查的是全球源条件，而不是任意选一个规范来拟合通量。
5. **作者的二维样条实现未公开。** 节点、端点、插值变量和精度会影响逐分量Hessian。作者报告KG迹达到机器精度，但单个收缩约束不等价于所有二阶导数准确。当前采用ODE导数并已有独立差分/坐标检验；目前没有证据指认作者样条存在错误。
6. **论文绘制的标量通量不是完整epsilon²q²总通量。** 原文明确还有未计算的引力及轨道频率修正。复现时应比较论文定义的同一量，不能擅自加入额外项作为“修复”。

本地原始资料定位：outputs/environment_reference/main_PRL.tex的Numerical Procedure and Validation；outputs/lorenz_reference/DirectLorenzGauge.tex引言第121行；outputs/lorenz_reference/LorenzGaugeKerrCirc.tex的球谐投影、轨道匹配章节及kappa附录。原始文献为2501.09806v1、2406.12510v3、2306.16459v3。
