# 主导视界通道的首次实际源结果

这是标量 (ell,m)=(0,0)，它由非静态度规 m_g=-1 与背景云 m_b=1
相乘产生。不要与静态度规 m_g=0 混淆；这条能流计算不依赖静态
补全模块的完成。

alpha=.3、a=.8771530275949366、rp=20、单位 Killing 云质量下，

    Omega_p=.011071760582072043,
    omega_c=.29629324847975713,
    omega=omega_c-Omega_p=.2852214878976851 < mu=.3.

因此该通道在无穷远衰减，没有无穷远辐射通量。首轮真实 Lorenz 源
积分 nr=4、nt=10、metric L=4、近视界16点对数积分、内截断.05：

    N_H=.006089663720342679,
    E_wave,H=.0017369029471126915,
    E_orbital,H=-6.742329873696426e-5.

这些量按 q² eta 归一化，eta=M_cloud/M，不能直接当作论文所写的
epsilon² q² 归一化。既有归一化差异仍未解决，不能宣称图2幅值吻合。

负号并非 m=0 标量波发生超辐射。此处正的波能量进入黑洞，云能量
变化为 -omega_c N_H，而轨道有效通量满足

    E_orbital,H = E_wave,H-omega_c N_H
                = (omega-omega_c)N_H = -Omega_p N_H < 0.

它表示该通道向轨道回馈能量。是否出现浮动轨道还取决于其余标量
通道与引力波通量，单独这个负值不能给出结论。

独立改变一项参数的比较：

| 改动 | 视界轨道有效通量 | 相对首轮变化 |
|---|---:|---:|
| 径向 nr=4 -> 8 | -6.74205121819e-5 | 4.13e-5 |
| 度规 L=4 -> 6 | -6.74232824172e-5 | 2.42e-7 |
| 内截断 .05 -> .005 | -6.73698162693e-5 | 7.93e-4 |
| 内截断 .05 -> .0005 | -6.70100568254e-5 | 6.13e-3 |

内截断试验还改变首段对数网格的跨度，因此仍需独立增加近视界积分点，
不能将全部变化归因于被截掉的物理积分。进一步内截断试验及状态
见 `scalar00_convergence.json`；该汇总只接受已有最终 flux 的数据。
总通量、角向加密、边界收敛与论文归一化核对仍未完成。

源在近视界并未显著发散：从距视界.05降至.0005，其投影绝对值
趋向约.0613，但复相位继续变化。截断差不能简单要求单调，因为
缺失积分会与已有复振幅干涉。已启动同一.0005截断下的32点对数
积分，以区分首段积分误差和真正缺失的视界区间。

后续32点结果与16点仅差3.75e-8。基于两个 Frobenius 相位的缺失
积分补偿已实现，显著减小内截断依赖；推导、阶数/区间变化与
新的 nr=8 数据见 `HORIZON_TAIL.md`。尚不能据此宣布总通量收敛。
