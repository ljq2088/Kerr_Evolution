# 弱模态径向加密核验

在 rp=20M、alpha=.3、Lg=18、角积分18点的相同参数下，将普通径向面板从8点加密到16点；首个对数面板仍为32点。源节点从88增加到144。两份结果的参数已逐项检查，仅 radial_order 不同。

(ell,m)=(12,6) 的无穷远轨道有效能流从 1.6965420409740824e-16 变为 1.6965420315336277e-16，相对变化约 -5.56e-9。论文图6读数约 1.2802158134573393e-16，约32.52%的差异仍存在。这次径向加密没有解释该差异。

视界能流从 -5.73962126105121e-27 变为 -5.440622974349765e-27，相对变化约 -5.21%。这说明不能把无穷远的稳定性推广到这一极小的视界分量。

完整数值、原始输入的 SHA256 和相同参数见 scalar12_m6_radial_refinement.json。这里没有改变首面板分辨率、角积分阶、度规截断或度规匹配，也没有进行整体误差证明。此结果不能标记为完整收敛或论文复现成功。
