# Kerr 束缚态极点与频率交叉

`environment_bound_spectrum.py` 对复频率求解角向特征值与两端径向
方程。在视界选ingoing Frobenius解，无穷远选空间衰减分支，
在中间半径匹配R'/R。通过alpha=.1→.3的连续跟踪识别与低耦合
无径向节点分支相连的|100>、|322>态，随后独立改变边界与容差。
这没有把真实频率扫描中的通量峰拟合成某个预设Lorentzian。

## 近视界稳定积分

设d=r-r+，b=r+-r-，x=log d，Y=dR/dr乘d。径向方程
(Delta R')'+V R=0变为

\[
\frac{dR}{dx}=Y,\quad
\frac{dY}{dx}=-\frac{d}{d+b}Y
-\left[\frac{K^2}{(d+b)^2}-\frac{dA}{d+b}\right]R,
\]

其中K=omega d(r+r+)+2Mr+omega-am（本代码M=1），
A=mu²r²+a²omega²-2am omega+lambda。该形式在近视界没有
Delta=r²-2r+a²的相消，也无需用极小的物理r步长推进。

最初直接r积分的复频率匹配出现约1e-10的残差噪声；改用上述
坐标后，|100>粗细两组频率相差约8.8e-13。此修改只用于新增谱
求解器，没有改动正在运行的Lorenz/受迫径向计算。
