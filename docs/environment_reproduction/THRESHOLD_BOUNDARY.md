# 近传播阈值的远区边界修正

本文件记录真实受迫标量计算发现的边界失效及修正，属于复现过程的数值
推导与证据，不是已经收敛的图5或图2。源仍只保留 ell_g=1,2，径向每
面板2点、首面板8个log节点、角向6点；尚需源积分与度规截断加密。

## 为什么原边界会给出错误通量

旧远区展开为 R=exp(ikr) r^p sum(c_n/r^n)，
p=-1+i(2 omega²-mu²)/k。k趋于零时系数迅速增大，固定r=1000
并不保证渐近展开有效。alpha=.3、标量ell=m=2时：

| 轨道 | omega | k | 在1000处最后一项/级数和 |
|---|---|---|---|
| 41.6 | 0.300008109274 | 0.002205817356 | 1.004 |
| 41.8 | 0.299981565664 | 0.003325697161 i | 1.089 |

旧41.6结果的无穷远有效能流为1.66e-32，但Wronskian变化仅约2e-11。
Wronskian只检验同一个齐次ODE的积分一致性，不能证明所选Up边界是
物理解。旧数据保留，并明确标记 historical_unreliable_boundary_result；
其中的真实源样本仍可复用。采样器现在拒绝最后一项相对比超过1e-3的
旧级数边界，要求选择Coulomb边界并做外边界收敛。这个阈值只是拒绝
明显失效的防护，不是误差上界或生产精度保证。

## 保留长程势的推导

从 (Delta R')'+V R=0 出发，令 y=sqrt(Delta) R，可得

    y'' + Q y = 0,
    Q = V/Delta - Delta''/(2 Delta) + (Delta')²/(4 Delta²).

使用Delta=r²-2r+a²、K=(r²+a²)omega-am，以及
V=K²/Delta-mu²r²-a²omega²+2amomega-lambda，逐阶展开得

    Q = k² + 2 beta/r + C2/r² + O(r^-3),
    beta = 2 omega²-mu²,
    C2 = 12 omega²-4 mu²-a²k²-lambda.

这里lambda是角方程本征值A，不是另加a²omega²-2amomega后的径向
分离常数。令z=-2ikr，方程变为Whittaker方程

    d²y/dz² + [-1/4 + kappa/z + (1/4-nu²)/z²] y = 0,
    kappa=i beta/k,   nu=sqrt(1/4-C2).

外出/衰减解使用W_{kappa,nu}(z)。传播情形按原论文远区幅度约定归一化：

    R_Up = N W_{kappa,nu}(-2ikr)/sqrt(Delta),
    N = exp[-kappa log(-2ik)-2ik log 2].

因此其极限是exp(ikr) r^(-1+i beta/k) exp(-2ik log2)，与原来的
exp(ikr*) r^(i mu²/k)/sqrt(r²+a²)一致。负频取带符号实k，保持复共轭
关系。束缚分支取k=i sqrt(mu²-omega²)，Up在外边界归一化为1；
这种任意幅度不改变Green解，也不产生无穷远传播通量。

对数导数用于边界初值：

    R_Up'/R_Up = (-2ik) W_z/W - (r-1)/Delta.

此构造保留完整Coulomb长程行为，没有截断beta/(k²r)的展开，但仍略去
O(r^-3)势项，因此仍须增加边界半径验证，不能直接宣称近阈值精确。
实现使用mpmath 1.3.0的Whittaker函数，边界值计算使用40位精度。

## 独立对照与当前结果

普通频率下，Coulomb边界与充分远处的旧级数边界向内传播后吻合，
外边界加大时误差下降；正负频率复共轭测试通过。

41.6使用同一组已保存源样本，Coulomb外边界1000、2000、4000、8000
时无穷远有效能流分别为1.80482830e-5、1.80489530e-5、
1.80488413e-5、1.80488593e-5。32000时为1.80488526e-5。
同时将旧级数边界推到2e6，最后一项相对比降为6.71e-8，得到
Z_inf=0.745089829931+0.739018179961i；Coulomb在8000处给出的
复振幅与它相对差1.49e-5。两种远区处理的对照独立于源重新采样。

41.8无穷远通量为零，32000处视界有效能流为-2.17436493e-6。
上述通量均按q² eta剥离，仍有论文epsilon归一化待核对问题。
数据见threshold_boundary_refinement.json和threshold_distant_series.json。

主项目测试：54 passed。这是边界修正及已有模块的测试结果，不是全篇
图级验收；尤其m_g=1完整点粒子匹配、所有模态、源截断和静态补全仍待完成。

## 后续真实源加密

固定Coulomb外边界32000，41.6轨道从每面板2点、角向6点、ell_g<=2
加密到每面板4点、角向10点、ell_g<=4（首面板8→16个log点），
无穷远有效通量从1.80488526e-5变为1.43013398e-5；视界从
-2.16729316e-6变为-2.17058495e-6。因此粗试算的幅度尚未收敛。
这是多种分辨率同时变化，不可将差异全归为径向误差。随后已启动仅将
径向每面板4→8点的计算，保持角积分、度规截断和边界设置不变。
汇总入口report_threshold_source_convergence.py明确记录每步改变的参数。
