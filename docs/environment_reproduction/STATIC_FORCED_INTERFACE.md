# 静态度规诱导的标量通道

`report_environment_forced_mode.py` 和批量程序现支持 `--static-matching`，
输入已经完成的静态精确荷匹配报告；同时指定 `--metric-m 0`。
静态度规、源投影、Green 方程使用同一 a、轨道半径和度规截断，
不一致即拒绝。源元数据记录匹配跳跃系数（包括变换后的自由标量）、
内外补全系数和边界约定，避免把不同候选度规视为同一缓存。

这里度规 m_g=0，但云 m_b=1，所以被激发的标量通道 m=1，
频率 omega=omega_c。对论文 |211> 背景，等赤道反射奇偶允许
ell=1,3,5,...。论文尾迹图排除了 ell<2，因此首先需要 ell=3,5,...。
这些通道对轨道有效能流的系数 omega-omega_c 为零，但其场值
一般不为零；不能因能流为零而在尾迹图中删去。

ell=1 对应背景束缚模自身，普通 Green 逆在阈值具有共振。
该通道需要可解性条件和频率修正处理；程序明确拒绝直接积分，
不能用一个很小但非零的数值 Wronskian 伪装成普通非共振响应。

已启动图1轨道 rp=3.5、alpha=.3 的 scalar(3,1)、(5,1) 试算，
使用 L_g=12、nt=16、每普通面板4点及近视界16点，匹配来自
`static_tetrad_a0.877153_r3.5_L12_q24_j12_free12_paper_eps5e-06.json`。
结果仍需源网格、度规截断和静态边界检验，不能据接口通过认为
静态扇区或图1已完成。

非静态及连续场原有76项测试通过，新增两项检查覆盖静态参数
误配与背景共振拒绝。度规缓存只复用同一个候选度规的张量值，
不同标量 ell 仍分别计算其投影源与径向响应。

## 合成场的约定

对于每个标量 m，都必须使用对应频率的扁球函数，而不能一律
替换为球谐函数。已有径向响应代表 Phi 的径向系数，不是 r Phi：

\[
\phi^{(1,1)}(t,r,\theta,\varphi)
=\sum_{\ell,m} R_{\ell m}(r)
 S_{\ell m}(\theta;a^2[\omega_m^2-\mu^2])
 e^{im\varphi-i\omega_m t},\qquad
\omega_m=\omega_c+(m-1)\Omega_p.
\]

故其绝对值随共转角 varphi-Omega_p t 刚性转动；公共相位
exp[-i(omega_c-Omega_p)t] 不影响绝对值。复标量场的负 m 通道
需要单独受迫求解，不能通过正 m 标量场的共轭补齐；之前可复用
共轭的是实度规。绘图时必须明确所保留的 ell,m 及坐标映射。
