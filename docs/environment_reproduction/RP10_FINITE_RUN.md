非静态mg=1..6顺序队列，每次使用8个径向采样进程。每个mg
同时计算所需正向和共轭度规驱动的标量通道，目标是无穷远
ell<=6的9个传播通道和视界ell<=5的18个非零有效通道。
mg=6的正向标量(7,7)作为批处理附加结果，不进入上述总和。

参数为重构编号Lg=18、nr=8、nt=18、首面板对数32点、内源偏移

## 首批结果与视界差异核查

仅标量(ell,m)=(0,0)的视界轨道有效能流已为
-6.272275267097329e-5，绝对值是上述论文总通量图值的
1.3877922943倍。它是一个已完成的有限分辨率单通道，不能当作
完整总和。不过对阈值云，所有非静态视界有效通道均满足
F_H=4 M r_+ mg^2 Omega_p (Omega_p-Omega_H)|Z_H|^2 <= 0；
在当前约定与近似下，补加其他通道不会用符号抵消这一差异。

保持这96个源采样点、权重、度规和归一化不变，将Green外边界
从1000M移至4000M，视界通量相对变化为-1.34870e-11；再将
径向积分rtol从1e-11收紧到1e-13，相对原始值变化为-4.32276e-12。
紧容差的Wronskian相对离散误差约1.01244e-12，有限求和条件数
约1.071。这里足以表明，这次外边界移动及积分容差变化没有
解释约39%的差异；并不证明源、角积分或度规收敛。

可复查数据为rp10_scalar00_horizon_boundary_audit.json，保存
原始响应哈希与三次运行参数。生成程序为
src/report_horizon_boundary_audit.py。批次数据为
scalar_batch_mg1_15f68e4b08e2.json，共六个标量响应；其中(6,2)
不计入ell<=5的视界清单。mg=2及后续批次继续运行。

在rp20角向对照批次完成后，已启动rp10的mg=1径向加密：
每个普通源面板从8点增至16点，首面板仍32点，其他参数保持
一致。一次共享度规计算提供标量m=2的ell2,4,6与m=0的ell0,2,4，
重点检查前述主导(0,0)视界差异。日志为outputs/rp10_L18_mg1_nr16.log。
完成前不声称源积分已经收敛。
