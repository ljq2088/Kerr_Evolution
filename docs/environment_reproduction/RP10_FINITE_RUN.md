# 第二个轨道半径的完整有限通量范围

rp=20M的非静态高负m队列结束后，已启动rp=10M、alpha=.3的
非静态mg=1..6顺序队列，每次使用8个径向采样进程。每个mg
同时计算所需正向和共轭度规驱动的标量通道，目标是无穷远
ell<=6的9个传播通道和视界ell<=5的18个非零有效通道。
mg=6的正向标量(7,7)作为批处理附加结果，不进入上述总和。

参数为重构编号Lg=18、nr=8、nt=18、首面板对数32点、内源偏移
.0005M、外源截止320M、Green外边界1000M。它们是有限分辨率
设置，并非已验证收敛；Lg=18与作者球谐截断的等价性仍未证明。

这组数据旨在将比较扩展到另一个轨道半径，检验rp=20M的差异
是否随轨道改变。不能只用单个主导模态代替论文的总通量。
归一化仍是q^2(Mc/M)，不根据论文曲线调整任何振幅。

report_flux_coverage.py现在接受--orbital-radius，按阈值云的
omega=omega_c+(m-1)Omega_p判断各通道是否传播，不再对任意
半径都假设m>=2即传播。原rp=20M的36/85清单数量不变；rp=10M
目标清单为9/18。目前新半径的模态尚未完成，清单总和为null。

日志为outputs/rp10_L18_mg1.log至mg6.log；现有rp20收敛及静态
计算继续运行，没有重启或替换。

## 独立原图参考值

从图2右面板的橙色Kerr曲线读取rp=10M，以线型区分无穷远
实线与视界通量幅度虚线。图坐标线性插值后，转换到q^2(Mc/M)
单位的参考值为：无穷远7.0116911126e-6，视界幅度4.5196066393e-5。
转换采用正文epsilon^2=alpha^6 Mc/M；视界图值本身只提供幅度。

report_figure2_radii.py同时核对五条径向网格线和四条对数通量
网格线，不读取任何计算结果。与此前20M读数交叉检查相对差
小于1.6e-7，来自对数格距取值精度。新结果保存在
paper_figure2_selected_radii.json，含PDF哈希和插值端点；没有
严格的图值误差界，不能代替作者原始数据。
