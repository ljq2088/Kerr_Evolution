# 原作者 HDF5：格式、基底对齐与质量检查

此次读取的是 ConorDyson/KerrLorenzMSF 在固定提交 `6b469f0835e42d3fa531b4997d7a912257119f60` 分发的真实作者样例。参数为 M=1、a=0.6、轨道 Boyer–Lindquist 半径 rp=8，m=1,2,3，径向/角向截断 ell<=4。文件没有属性记录实际生成提交，因此这是原作者分发的数值，而非本地执行作者求解器，也不能证明是 2025 年环境通量图使用的数据。

## 安全提取约定

`src/paper_author_hdf5.py` 直接读取每个文件自己的 `/m_m` 分组，绝不将 m=2 的量替换 m=1 的分量。示例：

```python
from paper_author_hdf5 import load_mode, COMPONENTS
d = load_mode(2)
r, c = d.nearest("In", 6.0)  # 返回真实最近网格的r；c[分量, ell]
r0, c0 = d.at_index("Up", 0)  # 轨道外侧真实r=8
```

- 十个量依次为 `h_l+l+`, `h_l-l-`, `h_m+m+`, `h_m-m-`, `rho_h_l+m+`, `rhob_h_l+m-`, `rhob_h_l-m+`, `rho_h_l-m-`, `sigma_delta_h_l+l-`, `h`。这是非归一化 tetrad 的加权投影，不是 BL 坐标分量。
- 自旋权为 `(0,0,2,-2,1,-1,1,-1,0,0)`；rho=r+i a cos(theta)，Sigma=r²+a²cos²(theta)，Delta=r²−2r+a²。tetrad 转换的原作者证据见 `h1FunctionalityAsymp.wl:401`。
- 每个复数由 float64 `Re/Im` 两个字段存储；In 为5×101，Up 为5×3960。ell=0..4；前九个量中的 ell 是最终球谐投影阶，已包含各生成 spheroidal 模态的总和。
- In 从r=8向内递减到1.80122174；Up 从r=8向外递增到987.55529414。两侧均保留轨道端点；rstar间距为0.25M。API不会插值或合并端点。
- 作者源公式显式设M=1，trace跳跃为 −16π S/(u^t Delta)，无额外小天体质量因子；这是单位小天体质量的扰动。比较时不额外拟合乘数，也不提前叠加负m。

## 迹分量的基底变换

原 writer `MetricReconstructRadiative.wl:2144` 直接输出 `hvec[[All,1]]`，是 spin0 spheroidal 的径向系数；前九个量经过 MRProjector 转为 spherical。原旧 bin reader 的第197–229行明确对trace做基底变换，HDF5 reader 第250–285行却没有这一步。因此不能直接用 q10 原始列表与本地球谐列表比较。

所用变换为 B[j,ell]=2π∫ Y_0jm(θ,0)* S_0ellm(θ;a m Ωp) sinθ dθ，q10_spherical=B@q10_raw。前九个量完全保持原值。Gauss–Legendre 64/96点给出一致B矩阵；最大绝对差为 4.552e-15。输出保留ell=0..4，只投影已存在的原始ell<=4输入，不凭空补高阶模态。

连续Lorenz度规的完整物理解应在轨道处连续。低ell截断、投影末端误差、不同生成副本以及具体导出路径均需排查；上述现象不能唯一判定作者公式、论文结果或本地实现错误。特别是fork若干生成副本把s=−1的下限写成lmins2，可能遗漏ell1,m1；本地暂时删除该向量项能改善部分样例比较，是识别样例生成路径的诊断，绝不是建议生产实现删除物理偶极。

m2/m3的若干前四分量已接近，但剩余分量差异仍较大。当前样例不够作为整个度规或2025通量复现的统一数值真值。须结合原作者求解器的可复现新运行与收敛检查再判断。
