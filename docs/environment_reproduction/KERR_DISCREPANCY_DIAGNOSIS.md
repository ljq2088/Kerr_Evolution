# Kerr通量偏差定位：尚未证实根因

本轮没有修改生产方程或归一化，不能宣称偏差已修复。

对alpha=.3、rp=20M，已独立求解仅含度规分离阶L=1的两组标量通道，并与L<=18完整响应在复振幅层面比较。全部径向/角向参数和Green边界相同。禁止把不同度规阶的单独通量直接相加：总量必须保留干涉项。

Kerr scalar(0,0)视界通量：完整L<=18为-6.7007499534e-5，L=1单独为-6.8056258788e-5；其余阶单独为-4.17858e-9，干涉项+1.05294e-6。高阶只使主导通量改变约1.6%，无法解释当前总通量与论文32.7%的差异。应优先核对偶极的trace/矢量源和边界匹配；这不等于已经证明偶极代码有错。

Schwarzschild同一通道：完整-1.3429107926e-4、偶极-1.3429061676e-4；符合它几乎完全由偶极贡献的预期。完整总视界通量还包括其他标量通道，不能用以上单通道值代替总量。

局部检查见kerr_discrepancy_local_exclusions.json。在r=2,5,10M、theta=1.1处，L<=4的Lorenz散度对标量源的补充项比主源小约1e-13..3e-11；Taylor阶6升至8的源变化为1e-13..6e-12。偶极kappa改用解析质量导数，四个样本的源变化均不到4e-9。它们不能解释百分之几十的差异，但也不是全域误差界。

完整点源匹配检查已在后台启动：rp20、mg1、L<=18、q18，采用确定性角向求解、解析kappa和扩展Taylor系数精度。日志outputs/rp20_mg1_full_source_matching.log。其目标是直接核查全部10个度规分量在粒子位置的连续性和投影导数跳跃；该检查已完成，结果见下节。

本轮新增report_metric_dipole_attribution.py，并通过3项测试，检验相消干涉保留、不同网格及不同物理参数拒绝。四个实际Kerr/Schwarzschild响应对均通过参数、网格、独立通量系数和复振幅分解核对。

另已查询arXiv页面，当前仅列v1；公开作者接受稿的图2也已查看，未发现可以直接解释现有差异的明显曲线替换。没有联系作者，也没有用图值校准求解器。

## 偶极 kappa 边界对通量的独立检查

新增 report_dipole_kappa_flux_audit.py：固定已保存的 L1、scalar00、nr8、nt18 源网格和标量 Green 函数，仅将 kappa 从生产有限差分质量导数替换为解析质量导数，分别使用远端边界 2000M、4000M、8000M。把源的复数差值积分为 delta Z，再计算 |Z+delta Z|²，保留干涉；不改生产模块或度规缓存。2000M 对照用于区分导数实现差异与边界变化。

新诊断中的 Hessian 实现已与既有协变导数实现对照：r=1.481、5、25M，theta=1.1，最大相对差异 6.5e-16。实际通量诊断已启动，输出为 dipole_kappa_flux_boundary_audit.json；程序完成前不作通量结论。

### kappa 通量诊断结果

诊断已完成。保存的基准视界复振幅重算相对差为 9.54e-17。

| 解析 kappa 远端边界 | 相对原生产通量变化 |
|---:|---:|
| 2000M | -2.24731922e-9 |
| 4000M | -2.24516317e-9 |
| 8000M | -2.24521512e-9 |

解析 4000M 与 8000M 之间通量变化约 5.2e-14；这里只反映固定源网格上的该项敏感度，不是总误差界。在本通道，本项不能解释 32.66% 的总视界偏差。

### 偶极 scalar00 径向加密完成

一般径向积分阶8→16、近视界阶32→64，源点88→176；已核实其他保存参数一致。视界通量从 -6.8056258787537e-05 变为 -6.8056258747927e-05，相对变化 -5.820249e-10，复振幅相对变化 3.841494e-10。该固定截断下的径向积分加密不能解释论文32.66%偏差；不能据此认定完整源或全部模态已收敛。结果见 dipole_scalar00_radial_refinement_comparison.json。
