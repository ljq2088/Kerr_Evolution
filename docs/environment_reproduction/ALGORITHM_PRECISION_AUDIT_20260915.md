# Kerr 算法精度审查：MST、GSN 与误差传播

日期：2026-09-15。参数：M=1，alpha=0.3，a=0.8771530275949366，rp=20。

## 结论与当前偏差

本轮找到了确定的 MST 低频实现错误和高 ell 重构病态，但没有证据证明它们解释了当前总视界通量约32.66%的差异。主导偶极扇区重新计算实际源后，HBL 与直接 Teukolsky 积分的视界通量仅相差9.42e-13。不能把“发现了一个库错误”说成“已修复论文主偏差”。

原论文比较覆盖下，当前视界有效轨道能流为 -6.86673237e-5，论文读图绝对值约5.176374e-5；无穷远为1.92103370e-5，论文约1.828765e-5。32.66%和5.05%分别是这两端通量大小的相对差，不是径向函数或波形振幅的误差。

## 1. 应否按频率切换算法

低频优先MST、高频优先GSN是可取的策略，但不存在只由一个固定Mω阈值决定的通用规则。MST允许复ν，GSN也能处理低频；角阶、自旋、径向位置、边界展开和级数计算的条件数同样影响精度。[Fujita–Tagoshi](https://arxiv.org/abs/0904.3818)，[Lo](https://arxiv.org/html/2306.16469v2)。

本例度规频率是 ω_g=m_g Ω_p，Ω_p=0.0110717605821，而不是云频率0.296293248480。m_g=1到6对应Mω_g=0.0111到0.0664，属于低频；但视界频率ω_g-m_g Ω_H=-0.285221487898 m_g，不能在旋转边界条件中作同样的小频率近似。

实际安装pybhpt 1.0.0的AUTO没有在MST/GSN间切换：MST分支被注释；仅当|ω r_min|>100尝试ASYMP，否则使用带稳定自旋变换的HBL。6组AUTO/HBL运行时结果逐bit相同。[固定版本源码](https://github.com/znasipak/pybhpt/blob/9fe9c57e2d1c92d944ba70ba3c1b81b665e9d274/cpp/src/radialsolver.cpp)。

该版本GSN只支持s=±2；本机独立Julia GSN参考库支持s=0,±1,±2，但没有可用Julia运行时，本轮没有运行Julia库。当前主导度规偶极涉及s=0,±1，不能用pybhpt的GSN直接替换。默认径向ODE rtol为1e-14；旧审查中的1e-13实际是放松容差，不能称为收紧。

## 2. 确定的MST库错误

v1.0.0 nusolver.cpp的标量低频分派将ell=2,3,4分别误送入ell=0,1,2展开；ell=0,1落入含奇异分母的通式。s=±1低频展开未实现，函数返回0，调用方又没有有效性回退。主导ell=m=1时，原始MST产生非有限径向函数；完整源计算在首个s=1 In调用被新诊断保护拒绝。

负频率路径还存在第三处错误：误差估计使用有符号epsilon缩放，负epsilon使估计值变负并可能提前接受初值，已改用绝对值。

修正方向为：修正标量低阶分派；s=±1采用monodromy求ν；使用MST三项递推连分式检查ν，随后检查R、R′、Wronskian及物理Green核。仅得到有限ν不足以宣布MST算法可靠。隔离补丁及验证结果见[低频MST修复报告](PYBHPT_MST_PATCH_VALIDATION_20260915.md)；没有替换正在使用的.venv库。最终21/21组ν通过独立65位连分式检验，最大绝对差7.49e-15；18/18组Kerr中间区域径向函数与Green核通过，包含3组负频率。包括Schwarzschild控制的全部径向判据为18/21，三个近视界Up缺陷仍保留；Kerr端点也有独立求值失败。

## 3. 径向后端交叉验证

共107次径向求解、14次ν对照，覆盖s=0,±1,±2、主导频率和m=1到6、最高ell=18、r=r_++0.001至316。对照按物理分段选取r<rp的In、r>rp的Up，同时检查归一化无关的Green核；未使用的另一支在端点失效应单独报告，不能自动等同于物理解失败。

| 检查 | 结果与含义 |
|---|---|
| GSN/AUTO，s=±2，r≥2M | 物理分段R、R′最大相对差约7.39e-10 |
| GSN/AUTO，r=r_++0.001M | 可达1.38e-4；GSN收紧到1e-15反而达到8.36e-4，存在变换/舍入限制 |
| 裸MST，高ell=18,m=1 | 个别物理Green核可偏近20%；GSN/HBL在同组约1e-11一致 |
| HBL默认1e-14→1e-15 | 主导spin2物理解变化约8.1e-15 |

上述发现反对在当前库中仅凭低频强制全部使用MST，也说明单纯降低rtol不保证提高精度。

## 4. 将误差传播到实际源与视界通量

重新生成主导度规ell=1、m_g=-1到标量(ell,m)=(0,0)的源：同一88个径向节点、18点角向投影，逐节点计算新度规，不复用旧度规或源缓存。保持角函数、trace/kappa求解和massive标量Green一致，只更换s=0,±1径向后端。

| 后端 | 标量00视界有效轨道能流 |
|---|---:|
| AUTO，实际HBL | -6.805625878766075e-5 |
| 直接TEUK | -6.805625878772487e-5 |

通量相对差9.42135e-13；复Z_H相对差4.72826e-13；源的加权L2相对差6.09028e-13。每个后端记录445次径向调用，并保存Python接口、扩展二进制及本地实现哈希。

这是主导偶极扇区在该有限网格上的实际响应对照，不是新的全L18总通量。HBL/TEUK可能共享边界展开和归一化，因此仍未独立验证这些共同约定，也未独立验证Lorenz重构或trace/kappa源的物理公式。

## 5. 其他类似根因的检查

**有质量标量传播问题单独验证。** 其频率是ω_s=ω_cloud+m_g Ω_p，远区波数为sqrt(ω_s²-μ²)，不能直接套无质量MST/GSN。固定全部21个实际源数组，修改DOP853容差、两端位置、渐近展开阶数及Coulomb/Whittaker边界：

| 修改 | 总视界通量相对变化 | 总无穷远通量相对变化 |
|---|---:|---:|
| rtol 1e-11→5e-14 | -4.82e-11 | -5.11e-11 |
| 外端1000→2000，内偏移1e-4→1e-5，远区6→12阶 | -7.97e-11 | -3.53e-11 |
| 传播通道采用Coulomb/Whittaker，外端4000 | +1.51e-12 | -3.59e-9 |

本例min|k|=0.06688，min|ω_s-m_sΩ_H|=0.28522，未接近质量阈值或视界同步阈值；Wronskian相消条件数最大2.172，主导00源积分相消条件数1.617，没有对应的灾难性相消。上述试验固定源和积分网格，不能验证共享源公式。

**高ell度规重构确有精度问题。** 对未改动的生产nonstatic_metric，Kerr ell=18轨道内外，仅将Taylor系数运算由complex128换为long double，局部度规范数变化0.264%和0.211%；ell=1变化仅1.52e-12和6.65e-12。将R、R′独立扰动约1e-12，高ell局部度规可变化25%–40%。该扰动试验故意打破误差相关性，只测条件敏感度，不代表实际径向误差就是这个水平。

大项来自高阶微分算子和不同自旋扇区，相互抵消。Schwarzschild高ell同样病态，且当前总通量由偶极主导，因此不能把高ell局部25%–40%变化等同于总视界32.66%偏差。long double也不是已经确认的真值：其径向和角向输入仍为双精度。

## 6. 正确的算法改进顺序

1. 使用经修复并通过连分式检验的ν，验证MST在每个物理径向区间的收敛；端点失败时采用稳定ODE传播，不能将单点ν修复当成全域精度保证。
2. 根据s、ell、a、ω、ω-mΩ_H、径向区域及误差诊断选择MST/HBL/GSN。比较归一化无关的核，再验证实际源响应；ω=0和质量阈值需专门处理。
3. 对高ell重构，保持关联自旋径向数据满足Teukolsky–Starobinsky恒等式，先解析消去大项，或采用已核对的显式十分量表达；输入到高阶运算的精度必须一致。仅减小ODE容差无法解决这种相消。
4. 要解释当前主偏差，接下来仍需优先对主导偶极的共享Lorenz重构、trace/kappa源和边界/归一化约定做独立验证。本轮结果已缩小范围，但不能以多个数值方法同意替代物理公式验证。
