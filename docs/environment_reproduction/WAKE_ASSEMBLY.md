# 连续场合成与切面诊断

`EnvironmentalWake` 将真实源重建的连续径向解与各通道自己的扁球
函数相乘，并保留复时间、方位相位。没有对复标量的负m通道施加
现实性条件；没有把径向系数额外乘r或除r。记录的场单位是
delta Phi / [q sqrt(Mc/M)]。

默认要求指定ell范围内所有反射对称性允许的m通道存在。缺失时
直接拒绝生成“完整”场；只在显式 `--allow-partial` 时绘制子集，
并把缺项写在图标题与JSON清单。重复通道、不同背景/归一化、
不一致的频率关系均拒绝。不同离散参数默认也拒绝，例外见下文。

当前 `wake_diagnostic_rp20_L6_sl5.png` 使用alpha=.3、rp=20M、
ell=2..5的16个已计算通道，明确缺少静态源诱导的(3,1)、(5,1)。
它不是论文图1或图5的完整复现，也不是未受扰动云密度图。
匹配的复场数组保存为NPZ，输入文件SHA256与缺项清单保存为JSON。

两幅图均在BL时间t=0。赤道面theta=pi/2，右图是y=0子午面，
含phi=0和phi=pi两个半平面。采用坐标标签的嵌入：

\[
x=r\sin\theta\cos\varphi,\quad
y=r\sin\theta\sin\varphi,\quad z=r\cos\theta.
\]

它不是Kerr–Schild笛卡尔坐标。黑圆表示r=r+的坐标截面，青色加号
标记位于(rp,0,0)的次级天体。色标表示扰动复场绝对值，不能把
颜色直接解释为总云密度、局部能流或完整引力波振幅。

测试用解析球谐检查正m、负m、m=0与轴上极限，并验证
omega_m=omega_c+(m-1)Omega_p所给出的共转相位恒等式；另用一个
实际源文件确认缺失模式会被默认拒绝，显式部分场会保留准确清单。
这些测试验证合成方法，不替代源和物理模态截断的收敛。

## 不同模态的数值边界

高阶传播通道需要更远的Green外边界，而衰减通道过远的边界可能
导致中间齐次解溢出。因此增加显式 --allow-mixed-discretization，
允许每个模态保留自己的源网格、截断与Green边界；没有插值到
共同源网格，也不把不同离散参数伪装成同一次收敛计算。

每个模态先独立重建连续径向解，再求场之和。可求值区域为所有
径向解有效区间的交集。不同的共同参数在 parameters 中记为 null，
各自的精确数值参数和度规来源保存在 mode_provenance。图标题标出
mixed discretization，文件名增加 _mixed，避免覆盖同网格诊断图。
即使所有指定模态齐全，状态仍然只是 complete_mode_range_not_converged。

实际源测试把(2,2)的4000M边界解与(3,3)的1000M边界解合并，
检查共同区域的场等于独立重建场之和、域外交叉求值被拒绝，
并验证显式允许不同网格不能允许不同alpha或云质量。
另生成并目视检查 wake_diagnostic_rp20_L18_sl3_mixed.png：实际包含
(2,0)、(2,2)、(3,-1)、(3,3)，缺少(2,-2)、(3,-3)、(3,1)。
此图仅验证合成与绘图流程，不能用于验收完整尾迹。

report_flux_coverage.py 现可指定角向阶数、无穷远/视界/场的ell范围，
并通过 --green-outer-by-m 显式选择每个标量m扇区的Green边界。
存在多份匹配的同模态数据时仍拒绝歧义，不自动挑选“最新”结果。
新增 field 清单包含静态 m=1 模态；绘图优先使用此清单，避免从
非零通量清单构造场时漏掉静态响应。

当前 Lg=18、nt=18、ell<=12 的覆盖快照只得到36个无穷远通道中的
11个、85个非零有效视界通道中的24个。这个快照不是完整图6，
总通量保持 null；正在计算的其他扇区完成后需重新生成清单。

静态 Lg=18 匹配实际运行暴露了辅助球谐数组越界：cos(theta)^2
将ell=18耦合到ell=20，超出默认20维数组。静态分支现在显式把
球谐矩阵扩到包含所需阶数。由于此处c2=0，不存在谱尾近似；
检验用Legendre递推关系独立计算标量耦合，以及分部积分恒等式

\[
\int x^2\nabla Y_{j0}\cdot\nabla Y_{\ell0}\,d\Omega
=\delta_{j\ell}+\left[\frac{j(j+1)+\ell(\ell+1)}2-3\right]
\int x^2Y_{j0}Y_{\ell0}\,d\Omega,
\]

检查ell=18、20及最高ell+2的角向jet，均通过。静态匹配的新一轮
实际计算仍在运行；未据此宣称匹配或静态场已经收敛。
