# 连续场合成与切面诊断

`EnvironmentalWake` 将真实源重建的连续径向解与各通道自己的扁球
函数相乘，并保留复时间、方位相位。没有对复标量的负m通道施加
现实性条件；没有把径向系数额外乘r或除r。记录的场单位是
delta Phi / [q sqrt(Mc/M)]。

默认要求指定ell范围内所有反射对称性允许的m通道存在。缺失时
直接拒绝生成“完整”场；只在显式 `--allow-partial` 时绘制子集，
并把缺项写在图标题与JSON清单。重复通道、不同背景/离散参数、
不一致的频率关系均拒绝。

当前 `wake_diagnostic_rp20_L6_sl5.png` 使用alpha=.3、rp=20M、
ell=2..5的16个已计算通道，明确缺少静态源诱导的(3,1)、(5,1)。
它不是论文图1或图5的完整复现，也不是未受扰动云密度图。
匹配的复场数组保存为NPZ，输入文件SHA256与缺项清单保存为JSON。

两幅图均在BL时间t=0。赤道面theta=pi/2，右图是y=0子午面，
含phi=0和phi=pi两个半平面。采用坐标标签的嵌入：

\[
x=r\sin\theta\cos\varphi,\quad
y=r\sin\theta\sin\varphi,\quad z=r\cos\theta.
\]

它不是Kerr–Schild笛卡尔坐标。黑圆表示r=r+的坐标截面，青色加号
标记位于(rp,0,0)的次级天体。色标表示扰动复场绝对值，不能把
颜色直接解释为总云密度、局部能流或完整引力波振幅。

测试用解析球谐检查正m、负m、m=0与轴上极限，并验证
omega_m=omega_c+(m-1)Omega_p所给出的共转相位恒等式；另用一个
实际源文件确认缺失模式会被默认拒绝，显式部分场会保留准确清单。
这些测试验证合成方法，不替代源和物理模态截断的收敛。
