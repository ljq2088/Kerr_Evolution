# rp=10M 的度规与角积分联合加密

修复高阶角向基底越界后，Lg=24、nt=24、nr=8、首面板h32的mg=1批次完成六个标量通道。结果为scalar_batch_mg1_d7551b4b26ac.json。源区间、面板、物理参数与Green边界均与原Lg18/nt18实验相同；另有角向基底扩展源码变化，故不将结果当作只改变Lg的实验。

主要(0,0)视界通量从-6.272275267097329e-5变为-6.272237784804143e-5，相对变化-5.97587e-6。三个m=2传播通道的无穷远通量相对变化绝对值均小于7.4e-9，其视界变化不超过5.8e-6；m=0的ell=2,4视界变化分别约1.14e-6、6.30e-6。逐项数据及输入散列见mg1_r10_metric_angular_refinement.json。

此联合加密没有消除rp10主导视界与论文图值约40.7%的差异。它也不能证明源规范、近视界截断和整个解已正确。下一步保持Lg18/nt18/nr8，将首个对数面板32点增至64点，六通道共享度规源；日志outputs/rp10_L18_nt18_mg1_h64.log。新旧源码在原阶数下的小差异仍需区分，不能将其隐去。
