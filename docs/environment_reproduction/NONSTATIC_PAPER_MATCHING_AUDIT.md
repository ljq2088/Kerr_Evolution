# 2023 年非静态匹配条件专项核查

尚未解决 Kerr 总视界通量的32.66%偏差。本轮修正了论文投影诊断的一个符号约定，并新增直接匹配检查；生产标量源、度规重构和通量公式未改。

## 从原文确认的关键条件

2306.16459v3的Construction of the metric perturbation / Determining the jumps明确要求：

- 对每个球谐阶，以十个指定标架分量的连续性及导数跳跃构成过定约束。
- m=±1、j=1不存在自旋2球谐函数，常用的h_mpmp两条条件退化。因此必须补充rho h_lpmp的j=1连续性及导数跳跃条件。
- 解线性系统后，作者通常丢弃与内部最高阶距离不超过6的模态；不能把内部最高阶等同于最后使用的数据阶数。

这些细节在2023参考文献中公开，但环境论文改装程序具体如何采用它们、内部最高阶及精度参数，没有给出完整实现。当前代码的辅助源法不显式解同一个匹配矩阵；是否满足这些物理条件必须直接检验。

## 修正：诊断中的l_minus方向

原文Eq. tetrad2定义：

    l_plus  = [(r²+a²)/Delta, 1, 0, a/Delta]
    l_minus = [-(r²+a²)/Delta, 1, 0, -a/Delta]

旧report_static_tetrad_matching.py使用了-l_minus。已修正为原文定义，并更新背景投影测试。新增测试独立验证

    g^ab = [Delta l_plus^(a l_minus^b) + m_plus^(a m_minus^b)] / Sigma.

背景度规的Sigma Delta h_lp_lm投影为+2 Sigma²，其径向导数为+8r Sigma；旧符号给出负值。旧诊断使用同一向量转换待匹配张量与目标，因此该修正不会改变一致构造下的拟合系数，不能作为32.66%通量偏差的修复。

初次非静态检查运行时也继承了这个方向。完成L1..8后，已将含奇数个l_minus的分量6、7、8及解析目标同时变号，转换到原文约定；误差绝对值不变。后续运行直接使用修正后的标架，恢复计算时逐项核对解析目标。

验证：test_static_tetrad_projection.py及test_nonstatic_paper_projection.py共3项通过。生产非静态度规仍使用原有Kinnersley标架，未受此诊断修正影响。

## 新增实际度规检查

report_nonstatic_paper_projection.py在rp=20M、a/M=.8771530275949366、mg=1下，对全部十个原文标架分量分别作自旋权重为0、±1、±2的球谐投影。目标由真实粒子四速度及坐标应力张量计算，投影范围j=1..6。没有用这些条件拟合或调整任何幅度，全部作为独立待检条件。

使用q24、确定性角函数、解析kappa质量导数、扩展精度Taylor系数，轨道两侧偏移5e-5M并通过二阶局部展开外推。径向基础输入仍是双精度。

额外的j=1、rho h_lpmp条件，其解析导数跳跃为约-2.598909612 i。相对导数残差：

这说明额外条件并非被整个遗漏，但也未达到原文完整匹配的精度要求。更高阶回升可能包含截断、基础函数误差与大项相消；尚不能据此求出物理通量误差。

已将内部上限扩至14、仍只检查j<=6，从而把所有待检阶留在内部上限6阶以外。后台日志outputs/nonstatic_paper_projection_extend.log；逐阶结果nonstatic_paper_projection_r20_m1_q24_j6.json。任务完成前不把部分结果称为匹配收敛，也不把这种高阶残差当成已发现32.66%偏差的原因。

## 内部扩阶及径向算法对照已完成

内部L=14、只检查j<=6，保留了至少8阶间隔。所有受检分量按各自最大解析跳跃归一后的最大导数残差为 2.789485e-03；m1额外j1条件的相对导数残差为 1.876415e-03。扩大内部范围没有解决匹配残差，不能宣称缺少最高阶缓冲就是根因。

新增report_radial_backend_invariants.py，在r=2,10,20,20.00005,40M对spin±1、±2及低阶/4/8/14阶检验归一化不变的径向Green核与对数导数。64组结果保存为radial_backend_invariants.json。

- AUTO默认与AUTO较严容差、HBL/TEUK的Green核差异最多约2.8e-13，对数导数差异最多约1.2e-13。
- MST在spin2高阶反而有更大差异：正spin2的最大Green核差异约2.9e-6，对数导数差异约3.7e-5。不能盲目把MST替换为生产算法。
- 初次尝试spin=-1、ell=1的MST返回非有限值；该次诊断正确停止，随后改用此扇区可用的HBL/TEUK对照。这个尝试没有改动生产输出。

这些径向单函数的微小差异仍可能在最终重构相消中放大，单函数对照不能给出度规误差界；但没有发现基础径向函数本身有百分之几十的偏差。当前最明确的问题是高阶重构精度和完整匹配尚未达标，尚未证明它解释主要通量差异。

本轮实际修复限于诊断标架与原文的对应，并非物理通量修复。全部后台诊断均已完成。
