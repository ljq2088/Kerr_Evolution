## 新轨道的传播通道与图像范围

在rp=3.5M，频率omega_m=omega_c+(m-1)Omega_p可为负。传播
判据是omega_m^2>mu^2，不能沿用rp=20M只有m>=2传播的结论。
ell<=12的无穷远清单包含61个传播通道，其中包含负频率通道。
所有负m场已经包含在83个非静态场通道的队列中。
