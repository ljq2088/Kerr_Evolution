# 静态圆轨道局部匹配：实现与未通过项

本项仍不是完整静态 Lorenz 点粒子解。后续已验证远离模态截断边缘的
Kerr 局部跳跃条件，但物理边界尚未施加，不能接入论文尾迹或总通量验收。

## 圆轨道对称性修正

单支 IRG 经 Lorenz 变换并加复共轭后，虽然具有正确的两种极端 Weyl
曲率，仍可包含违反圆轨道对称性的规范部分。Kerr 度规及静态圆轨道
应力张量在 I:(t,phi)->(-t,-phi) 下不变，因此采用

    h_circ = (h + I* h)/2,
    (I* h)_ab = p_a p_b h_ab, p=(-1,1,1,-1).

这是张量拉回的平均，不是逐点削减误差。它消去 tr、t theta、r phi、
theta phi 分量。线性化 Einstein 算子和 Lorenz 条件与背景等距变换
可交换，故真空解及规范条件得以保持。独立曲率计算还验证圆轨道
源的 Psi0/Psi4 保持不变：在 a=0/.6、ell=2/3、轨道内外的测试点，
相对差约 1e-15。未对未验证的一般源作此假设。

实现位于 sourced_static_spin2；circular_symmetry=False 保留原始分支
供对照。静态 spin-2 底层函数仍返回原始复 IRG/Lorenz 分支。

## 匹配方程

particular 度规是 ell>=2 的 sourced spin-2 与偶数 ell trace 之和。
各分支 chi、kappa、B 的 particular 径向数据仍在 r0 取零。
加入自由标量 Hessian 及 B,C,D,E,F,G 补全：

    h_free,ab = nabla_a nabla_b kappa,
    kappa = R_j(r) Y_j0(theta),
    (Delta R_j')' - j(j+1)R_j = 0.

每个偶数 j 使用 r0 处 (R,R')=(1,0),(0,1) 两个局部基。
由于 Ricci=0 及 Box kappa=0，该 Hessian 无迹且满足真空 Lorenz 方程。
系数只表示 outside-minus-inside 跳跃，不能解释为最终 Up 振幅。

所有十个协变分量采用光滑角向向量 sin(theta) partial_theta 投影，
测试函数是 P_j(cos theta)。两侧 order-8 Jets 在 r0±epsilon 求值，
通过二阶 Taylor 继续到轨道。目标是

    [h_ab]_j=0,
    [partial_r h_ab]_j = -8 P_j(0)/(ut Delta0)
                            (u_a u_b + g_ab/2).

常规诊断同时拟合这两个条件；它不能独立验证导数跳跃。
--continuity-only 则只拟合场连续性，代数消元严格施加
Delta c_E=E、Delta c_G=L-aE，把所有导数跳跃保留作独立验证。
早期不带 exactcharges 后缀的数据把守恒量作为最小二乘行；这些数据
保留为历史诊断，不能与后续严格约束试验混为一谈。

报告缩放为 h_ab/(L_a L_b)、r0 partial_r h_ab/(L_a L_b)，
L=(1,1,r0,r0)。这是坐标分量诊断尺度，绝不是通量误差界。
列范数归一化前先排除几乎没有投影的列，避免把舍入噪声放大。

## 结果与限制

全部在 r0=6、epsilon=5e-5。

* a=0、L=6、12点角积分，拟合 j<=4：缩放残差 8.87e-10。
  E/G 未施加而独立恢复至约 4e-10/2e-10 绝对差。
  该小残差包含用于拟合的导数条件，不能当作独立导数验证。
* a=.6、L=6、free j<=6、12点、仅连续性拟合 j<=4：
  低阶 j<=2 的值/独立导数残差分别 2.67e-6 / 6.66e-6。
* a=.6、L=8、free j<=8、16点、仅连续性拟合 j<=6：
  同样 j<=2 的值/独立导数残差为 7.09e-8 / 9.02e-7；
  j<=4 为 1.97e-6 / 4.34e-6。
  但最高拟合阶附近的导数残差仍达 5.90e-2，因此整体未通过。

这两次 Kerr 试验同时改变截断、角积分和拟合阶数，只能说明低阶
结果改善，不能独立量化其中任一误差来源。还要固定物理投影阶数
提高各项分辨率，检查补全系数、自由标量自由度和 Taylor 外推。
让过高的自由标量阶数只受低阶投影约束可出现显著病态；对应失败
试算也保存，不能从小的拟合连续性残差推断物理解正确。

原始未施加圆轨道对称性的 L4 试算标记为 historical，保留它说明
为什么真空验证与 Weyl 验证本身不足以证明完整点粒子匹配。

即使局部条件全部通过，还必须把 particular 的全局齐次自由度
适配到视界/无穷远，并明确采用正确质量角动量解还是 Berndtson 解。
参考半径为零数据的当前补全基不能直接套用论文的边界适配系数。

复现入口：src/report_static_matching.py。数据为同目录 static_matching_*.json。
新增独立对称性/自由标量测试通过，主项目 tests 共 62 passed。

## 论文四标架条件：局部问题已获得收敛证据

以上坐标分量最小二乘会让截断边缘的误差影响低阶系数。改用
2306.16459v3 Sec. IV 的独立匹配条件后，可以直接分辨这个影响。
代码为 report_static_tetrad_matching.py，使用同一批已保存的协变
度规数据，不重复或另行调节 Weyl 源的振幅。

采用未归一化的四标架

    l+ = [(r²+a²)/Delta, 1, 0, a/Delta],
    l- = [(r²+a²)/Delta,-1, 0, a/Delta],
    m+ = [ia sin(theta),0,1,i/sin(theta)],
    rho = r+ia cos(theta).

投影五个量 (h_l+l+, h_m+m+, rho h_l+m+, Sigma Delta h_l+l-, h)，
分别使用自旋权 (0,2,1,0,0) 的球谐。m=0 球谐按

    S_j,s(x)=sqrt[(2j+1)/(4pi) (j-s)!/(j+s)!] P_j^s(x)

归一化，2pi integral S_j,s S_k,s dx=delta_jk。
整体相位约定不影响匹配；目标跳跃使用完全相同的投影。
若 W(r,theta) 是四标架收缩权，则必须包含

    partial_r(W h)=W partial_r h+(partial_r W)h.

独立测试以 Kerr 背景度规验证这个乘积规则，得到
Wg=(0,0,0,-2Sigma²,4)、partial_r(Wg)=(0,0,0,-8rSigma,0)。

严格固定 E/G 后，只用论文列出的连续性条件求其余未知数：

    (h_l+l+)_0, (Sigma Delta h_l+l-)_0,
    (rho h_l+m+)_1, (rho h_l+m+)_2,
    (h_l+l+)_j, (h_m+m+)_j, j=2,4,...,free_ellmax.

线性系统同时处理实部和虚部，检查满列秩；所有其他连续性条件及
所有导数跳跃均不参与求解。没有通过加入导数数据来压低验证残差。

a=.6、r0=6、角积分20点、L=free_ellmax=12 时，j<=8 的结果：

| 轨道两侧间距参数 epsilon | 最大连续性残差 | 最大独立导数残差 |
|---|---:|---:|
| 5e-5 | 5.27e-14 | 5.42e-9 |
| 5e-6 | 2.13e-13 | 5.42e-11 |

在 j=2,4,6,8，导数误差缩小比分别为100.033、99.989、100.069、99.988。
这与二阶 Taylor 外推误差一致。L=8 时仅更低阶区域达到同样精度，
提高 L 将未收敛的边缘向更高 j 推移。当前数据不证明所有 j 已收敛：
L=12 的 j>=10 仍有显著截断误差。

独立求得补全跳跃 B=-.17354797550703、D=.19491814467312、
F=.025072823249779，均落在参考论文表格所印数值的末位舍入区间。
E/G 是预先施加的守恒量，不能计作独立成功。C 和自由标量跳跃受
particular 及齐次规范选择影响，未宣称与论文采用同一基。

固定其余设置，将坐标诊断的角积分从20点增至24点，系数最大绝对
变化2.14e-14、缩放导数残差变化2.11e-15，排除了该算例的角积分
分辨率不足作为主要误差来源。汇总数据为 static_matching_convergence.json，
图位于 outputs/environment_validation/static_matching_convergence.{png,pdf}。

进一步检查图1的强场参数 a=.8771530275949366、r0=3.5，L=12、24点、
epsilon=5e-6：j<=8 的全部连续性残差最大3.68e-15，独立导数残差
最大5.45e-10。该算例尚未单独做 epsilon 加密，不能将此数值视为
经过多分辨率确认的误差界。

后续入口：为 chi、trace kappa/B 和自由标量选择真正的 In/Up
齐次部分，独立检验视界与无穷远正则性、质量和角动量约定；继续
提升模态截断覆盖论文所需范围。局部成功不能替代这些边界检查。
