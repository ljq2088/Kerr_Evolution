# 完整受迫源的确定性角向诊断

新增显式参数`--dense-angular`，用于非静态Lorenz度规的完整径向
源投影与Green响应。它保持C++径向求解器、标量角向投影、云和
通量定义不变，仅替换此前诊断过的四个Python角函数引用。
它不改变默认算法，也不表示新算法已经达到论文精度。

运行开始前检查过程内的源振幅及度规缓存。默认缓存已产生时，
拒绝切换到dense；安装dense后，拒绝请求默认算法。子进程首次
使用反序列化的度规对象时，先安装相同算法，再重构任何源或
真空因子。诊断结果的度规元数据带angular_backend，输出文件
带_denseangular后缀；缓存键包含后端和其实现内容。既有源复用
和截断扩展要求后端一致，默认通量清单排除诊断数据。

隔离进程测试核对了默认和dense缓存不共用、子进程结果与直接
计算一致、恢复读取逐项相同，以及拒绝混用已有源振幅缓存。
与原缓存测试合计3项通过。后端校验位于原静态共振保护之后，
保留其拒绝普通Green求解的行为。修复校验顺序后重新运行完整
回归，98项通过，用时237.87秒；日志为outputs/regression_dense_final.log。
测试通过只验证所覆盖的实现行为，不等同于论文通量或尾迹已复现。

尾迹合成器也将angular_backend计入数值设置：默认拒绝未经显式
允许的后端混合；允许混合时，各模态保留后端元数据，公共后端
标记为null。相关尾迹测试7项通过，包括该新检查。它不改变
任何已有场值或默认计算算法。

已启动Lg=18、nr=8、nt=18、首面板32点、源外界320M的mg=5
计算，标量通道为(6,6)、(8,6)、(10,6)、(12,6)。完成后才能比较
完整通量；已有几个节点的差异不能当作全积分误差。
