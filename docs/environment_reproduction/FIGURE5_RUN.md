# 图5阈值邻近轨道的受迫场计算

目标仍是rp=41.6和41.8的完整尾迹与收敛。先启动决定传播/束缚转换的标量m=2、ell=2,4,6,8,10,12扇区：alpha=.3，阈值Kerr自旋，Lg18、nt18、nr8、首面板对数32点，源内偏移.0005M、源外320M。

近质量阈值使用Whittaker–Coulomb远边界32000M，避免已知逆r短级数失效。12个齐次径向系统预检查均完成，Wronskian有限；41.6的全部m2通道为传播分支，41.8为束缚分支。见figure5_m2_boundary_preflight.json。预检查不证明边界或受迫场精度；还需改变远边界验证。

41.6使用8个采样进程，41.8使用4个，日志分别为outputs/rp41p6_L18_nt18_mg1_coulomb32000.log及outputs/rp41p8_L18_nt18_mg1_coulomb32000.log。两批均只含m=2。不能用它们的完成状态代替其他m、静态扇区或完整图5。m=0共轭驱动必须独立求解，不能直接用m=2复共轭替代；其束缚尺度也不适合未经检查地沿用32000M远边界。
