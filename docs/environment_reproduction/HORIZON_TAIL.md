# 视界缺失积分的渐近补偿

目标是控制实际 Lorenz 源积分的内截断误差，而不是按论文通量拟合
归一化。以下只适用于实频率、非零视界频率及精确同步的 Kerr |211>
背景；冻结衰减的 Schwarzschild 云与零视界频率均被当前入口拒绝。

令 x=r-r+、d=r+-r-，

    gamma=[(r+²+a²)omega-a m]/d.

从 BL 到 advanced Kerr 的相位变换可知，正则的入射源满足
J=x^(-i gamma) sum s_n x^n。齐次 Up 解在视界附近是两个分支的组合，

    R_Up=A x^(-i gamma) sum p_n x^n
         +B x^(+i gamma) sum q_n x^n.

因此视界振幅的积分核 F=R_Up J/W 必须具有

    F(x)=sum a_n x^n + x^(-2i gamma) sum b_n x^n.

把截断距离记为 c，拟合变量使用 z=x/c。常数相位及所有径向归一化
都由实际积分核的复系数吸收，不另乘人为的波形归一化因子。遗漏区间
可直接积分：

    delta Z_H=integral_0^c F(x) dx
       = c sum_n [a_n/(n+1)+b_n/(n+1-2i gamma)].

实现 `environment_horizon_tail.horizon_tail` 读取已有实际源样本，
按列归一化后解复最小二乘，同时报告秩、条件数、拟合残差及可用时
的留出样本残差。半径区间和多项式阶数变化用于诊断，不能作为严格
外推误差界。测试用独立的半无限区间积分核验解析积分，覆盖正负 gamma。

## 标量 (0,0) 实际数据

固定 alpha=.3、rp=20、度规 L=4、角积分10点，均按 q² eta 归一化：

* 内截断 c=.0005，近视界16点与32点积分的未补偿通量分别为
  -6.70100568254e-5、-6.70100593361e-5，相对差3.75e-8。
  这表明此前 .05 -> .0005 的约 .6% 变化主要来自缺失区间。
* nr=4、32点近视界、一次展开，拟合区间 c..5c、c..10c、c..20c
  的补偿后通量分别为 -6.69796767590e-5、-6.69796758870e-5、
  -6.69796754273e-5。
* nr=8、其余相同，三种区间分别给出 -6.69769139205e-5、
  -6.69769130486e-5、-6.69769125889e-5。nr=4 -> 8 的影响仍约4.1e-5，
  比这三个区间之间的差异大，不能只用很小的区间差宣布总误差很小。
* 较大截断 c=.005 的补偿值同样接近 -6.6979e-5，但取样不足或
  展开误差较大，不用它作高精度基准。

增加多项式阶数未必更可靠。例如32点数据、c..5c 区间仅含9个样本，
二次展开的列归一化条件数约1.51e4，且没有足够的独立留出点；其结果
比一次展开更不稳定。所有失败或不足的组合在 `horizon_tail_audit.json`
中保留，不选择最接近期望通量的一组来掩盖这种差异。

本修正目前作为独立审计输出，未覆盖原始有限截断结果，也未自动
应用到所有通道。完整径向、角向、度规截断和其他模态仍要收敛。
这也没有解决此前的 epsilon 与云质量归一化差异。

## 取样复用

`report_environment_forced_mode.py` 的 `--reuse-source` 可以重复给出。
每份缓存仍检查源的物理参数；相同半径的冲突数据会触发错误。
这样将原有 nr=8 的外侧网格与32点近视界网格组合，88个节点全部复用，
无需为同一个物理源重新构造昂贵的度规。数据中的 reused 标记可核验。

主项目测试71 passed。更高 L 的同截断/网格试算仍在进行，图级目标未完成。
