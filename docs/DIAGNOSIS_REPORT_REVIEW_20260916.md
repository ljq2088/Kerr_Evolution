# Kerr 视界通量诊断报告复核

日期：2026-09-16。输入：用户提供的 `Kerr_environment_horizon_flux_diagnosis.md`，SHA-256 `e328bd393ce669e440789c2ef5a20fe6a8c7b12eb118b267ece17595d06932a0`。

**结论：诊断报告发现了真实的公开代码门限错误，但将它认定为当前论文复现偏差的原因，证据不足，而且其“只删除矢量偶极即可解释偏差”的具体假说被本轮实验否定。当前约 32.7% 的 Kerr 视界总通量差异，仍不能唯一归因于解析错误、数值精度或论文错误。** 本次确认的是一个错误归因，并将仍未解决的差异进一步约束到主导标量 00 通道及其输入／源／幅度定义。

本次新增诊断脚本和结果，没有通过删除物理分量、调整归一化或乘拟合因子改变生产结果。以下“完整”指当前完整重构实现，“删除”指固定其余条件的反事实诊断，均不代表已经完成了论文全链独立验证。

\]
\[
M\omega_c=0.29629324847975713,\quad m_b=1.
\]

## 2. 报告指出的代码错误确实存在

某些公开的 `MetricReconstructRadiative.wl` 副本把 spin-1 模态的最低阶数设成 spin-2 的下界：

\[
\ell_{\min}^{(1)}=\max(1,|m_g|),\qquad
\ell_{\min}^{(2)}=\max(2,|m_g|).
\]

在 spin-1 生成和网格装配中误用后者，确实可能丢掉 \(\ell_g=1,|m_g|=1\) 模态。它是**程序逻辑／模态截断错误**，不是舍入误差，也不是 Teukolsky 方程的解析推导错误。

但有两个区别决定了它不能直接成为论文归因：

- 原 Sam 实现和另一个 Ret 副本使用正确下界，作者公开仓库并非只有一种执行路径。
- 2026-06-02 的提交加入了修正版目录；旧版及另一份新加入的旧副本仍存在。公开历史没有锁定 2025 年图 2 实际使用哪一份。

[历史证据复核](LEGACY_VECTOR_HISTORICAL_REVIEW_20260916.md)保存了原始提交、逐路径 blob 和完整差异。论文补充材料 S.5 说使用模块化包，未给出与这些公开文件对应的运行版本。不能把这句话扩大成“图 2 已证实由这个错误版本产生”。

另外，本次追踪了这两个门限的数据依赖：它们不反馈到 κ／trace 跳跃匹配。联立匹配仍使用正确下界；错误发生在随后将 spin-1 径向数组置零。故在这两个具体副本内，其直接影响确实等价于固定其他扇区、删除 spheroidal ℓ=1 生成的完整 vector 张量，包括所有角向混合后的分量。本轮消融采用的正是完整张量删除，未将它混同为只清零最终 spherical ℓ=1。这个数据流核验不等于整个历史生成器已经重新运行。

## 3. 决定性消融：删去该分量会向相反方向移动

在 \(\alpha=0.3,r_p=20M\) 下，保持云、坐标、源项定义、Green 核、积分网格和通量前因子不变，只从完整复源中减去 \(\ell_g=1,m_g=-1\) 的 spin-1/vector。它驱动标量 \((\ell,m)=(0,0)\)。得到

\[
Z_{\rm full}=-0.0496101415924+0.0335053762021i,
\]
\[
Z_V=0.0925388758677-0.0433457331826i,
\]
\[
Z_{\rm drop}=Z_{\rm full}-Z_V
=-0.1421490174601+0.0768511093848i.
\]

同一前因子 \(C=-0.0186974566058\)，\(F^H_{00}=C|Z|^2\)，所以

| 同一个标量 00 通道 | 视界有效轨道能量通量 |
|---|---:|
| 完整结果 | \(-6.7007503411\times10^{-5}\) |
| 只保留 vector | \(-1.9524437879\times10^{-4}\) |
| 从完整结果删除 vector | \(-4.8823614232\times10^{-4}\) |

删除后绝对值变为完整结果的 **7.28629 倍**。这里没有把 00 通道冒充总通量；它与论文总量的关系在下一节严格说明。

错误推断出在忽略复振幅干涉。实际满足

\[
F_{\rm full}=F_{\rm drop}+F_V
+2C\operatorname{Re}(Z_{\rm drop}\overline{Z_V}),
\]

其中交叉项为 \(+6.1647301770\times10^{-4}\)。vector 在完整振幅中产生强烈的相消干涉，删除它会破坏这种抵消。单看某一源分量“很大”，不能预判删掉它后通量变小。

甚至不能用“只丢了一部分”挽救这个方向。令

\[
Z(\lambda)=Z_{\rm full}-\lambda Z_V,\quad\lambda\ge0,
\]

则本点直接给出

\[
\frac{|F_{00}(\lambda)|}{|F_{00}(0)|}
=1+3.372521712\lambda+2.913768889\lambda^2.
\]

对全部 \(\lambda\ge0\) 单调增大。固定其他扇区时，减少同一 vector 分量不可能使本地通量趋向较小的论文结果。

**精度及独立积分检查：**

- 基准使用相同的 88 个径向节点、18 个角向节点，完整源回代与保存振幅相对差 \(2.6\times10^{-16}\)。
- vector 精化为 176 个径向节点、24 个角向节点，同时提高导数阶数并收紧 Green 容差，振幅相对变化 \(1.25\times10^{-9}\)。没有将精网格 vector 与粗网格完整源混合冒充精网格总通量。
- 第二条计算路线通过纯规范诱导标量的 Green 边界恒等式，代替直接 Hessian 源体积分；与直接积分相对差约 \(10^{-8}\)，受轨道单侧外推剩余误差限制。
- 两条积分路线共享同一个 vector 度规模型，不能单凭它们一致证明全部物理输入；此前原 Sam 程序的实际参数抽样对照为该模型提供了另一项有界的支持。

具体数据见 [同网格消融及精化核查](environment_reproduction/legacy_vector_ablation_alpha03_r20_audit.json)。

## 4. 无需等待全模态消融：视界符号给出严格反证

论文的阈值 Kerr 云满足 \(\omega_c=m_b\Omega_H\)。受迫频率及方位数为

\[
\nu=\omega_c+m_g\Omega_p,\qquad m=m_b+m_g,
\]

因此

\[
\nu-m\Omega_H=m_g(\Omega_p-\Omega_H).
\]

代入论文有效轨道能量通量式得

\[
\boxed{F^{s,H}_{\ell m}
=4Mr_+m_g^2\Omega_p(\Omega_p-\Omega_H)|Z^H_{\ell m}|^2\le0}
\]

适用条件为本例的 \(0<\Omega_p<\Omega_H\)，且使用相同的角向范数和通量定义。\(m_g=0\) 为零。不同角模态经球面积分正交，故没有跨模态的正贡献抵消。

所以删除后，不论其他模态如何变化，

\[
|F^{s,H}_{\rm total,drop}|
\ge |F^{s,H}_{00,drop}|
=4.88236\times10^{-4}
\simeq9.432\,|F^{s,H}_{\rm paper,total}|.
\]

这已经否定“固定其他约定，只漏 vector 就能解释论文总量”的假说。它不等于重新运行整个旧生成器。对已检查的两个门限，数据流排除了它们反向改变 κ／trace 匹配的可能；若再假定别的独立错误或归一化同时改变，必须作为新假说另做实验。

这个符号界也进一步定位了原来的偏差：**完整 00 通道本身就比论文总量大 29.45%**。仅增加／减少其他非正高阶通道，无法修复完整 00 超过总量的矛盾。在同一通量前因子下，若论文总量正确，必须有

\[
|Z^{H,\rm paper}_{00}|\le0.05261645,
\quad |Z^{H,\rm local}_{00}|=0.05986465.
\]

即该主导通道的振幅模长至少要下降约 **12.1%**，或者两边比较的输入／规范／幅度与单位定义并不相同。总通量一个实数无法确定这个复振幅究竟在哪个模块产生差异。

## 7. 还必须纠正的理论和历史推断

**删 vector 不一定破坏两侧真空 Lorenz 条件。** 该扇区是 traceless vacuum Lorenz pure gauge。它在每个光滑真空区域单独满足约束，但逐侧删除会改变轨道球面的拼接。作为分布的 \(C^b=\nabla_a\bar h^{ab}\) 包含 \([\bar h^{rb}]\delta(r-r_p)\)；分段规范向量也会产生接触项。不能把删除结果直接当成另一个满足同一粒子源的解。

**Schwarzschild 不是可以忽略的反证。** 这个门限没有自旋 \(a\)，球谐极限的非静态矢量偶极也不自动为零。论文 S.5 报告 Schwarzschild 度规全模式验证，例外是静态 \((1,0)\) completion，不能混同非静态 \((1,\pm1)\) 漏项。若要坚持论文走了错误路径，必须解释它如何同时通过该验证。

**论文不等于完全没有疑点。** 正 \((2,2)\) 视界通量的一句话没有明确区分同图的两个背景：若用于精确阈值 Kerr，便与该文频率及通量公式的上述非正结论冲突；若指 Schwarzschild，则可以成立。应标记为适用背景表达不清，不能据此认定其代码用错符号。论文也明确承认 scalar-only 通量不是该阶完整规范不变量；这要求比较相同规范和相同部分量，不能自动解释本次复现差异。

完整推导及固定原文行号见 [理论复核](LEGACY_VECTOR_THEORY_REVIEW_20260916.md)。

## 8. 剩余问题已经缩小，但尚未唯一定位

受迫问题可写成

\[
Z^H_{00}=\int K^H_{00}(r)J_{00}(r)\,dr,
\qquad F^H_{00}=C_H|Z^H_{00}|^2.
\]

本次证据最强的结论是：保留完整 vector；不要靠切换已通过检查的径向后端或统一调幅拟合论文；优先对照**同一实际参数下的归一化云、原始 \(J_{00}\)、Green 核及 \(Z^H_{00}\)**。

可识别差异位置的最小数据是：\(a,\omega_c,\Omega_p\) 与单位说明；同一径向网格的归一化云及导数；轨道两侧的 \(J_{00}\) 或原始度规数据；\(R^{Up}/W_0\) 与最终复 \(Z^H_{00}\)；以及图 2 使用的代码／数据版本。固定其中三项、交叉代入另一项，才能区分云／度规／协变源／径向传播／幅度归一化的差异。抽样原 Sam 度规一致并不能替代原 2025 环境源数组。

若这些原始产物继续不可得，仍可继续做本地全域独立算法与匹配认证；但结果只能进一步缩小本地误差范围，不能在逻辑上证明作者当年的计算出错。**现阶段应修正的是诊断报告的因果结论，而不是删去物理分量以制造与论文的符合。**
