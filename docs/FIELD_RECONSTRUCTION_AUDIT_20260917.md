# 空间标量场重构与图5峰值审查

本轮没有找到 `SampledResponse` 或 `EnvironmentalWake` 中足以解释图像振幅差异的实现错误。对现有源作独立Green积分、独立椭球角函数和时空相位组装，结果与生产重构一致。更重要的是，现有视界模式通量本身要求近视界场幅度明显大于0.04；不能把论文色条顶端直接当成场的全局最大值，进而靠缩放或改相位追随它。

## 独立计算覆盖与结果

审查覆盖rp=20的(ell,m)=(2,−2),(2,0),(2,2),(3,1),(3,3)，及rp=41.6的同五模式加(4,2),(6,2)，共12模式。每个模式在六个半径求R和R′：源内截断以下但在径向积分域内的r++0.00025、图5峰值半径1.5430279、r=3、轨道位置、100、200。

独立路径重新构造Gauss源节点的重心插值多项式，在每个观测半径处分割积分面板，用固定64点/128点Gauss求积直接计算两项Green解，不使用SampledResponse的累计ODE或其积分缓存。角向采用SciPy的prolate/oblate角函数，以单位球面范数和标准球谐相位固定约定。没有拟合场的幅度或相位。

| 检查 | 最大差异 |

| SampledResponse与独立Gauss128，R/R′相对差 | 1.531e-09 |

这些是不同重构路径的核验，共享原始源样本和齐次径向解。它们不检验原始源样本之间的插值误差，也不能认证源本身、全套度规或论文的规范约定。

## Green符号、正负模态与相位

使用W=Delta(u v′−v u′)，直接解为

`R(r)=v(r) integral_inner^r[u J/W] dr′ + u(r) integral_r^outer[v J/W] dr′`。

其导数为v′A+u′B；两项含J的导数交叉抵消。现有实现中右积分反向推进时显式加负号，随后存储从观测点向外的正向积分，符号一致。源内截断以下直接验证R=u ZH，无额外r、sqrt(r²+a²)或负号因子。

各标量模式使用 `m_scalar=1+m_g`、`omega_scalar=omega_c+m_g Omega_p` 和 `exp[i(m_scalar phi−omega_scalar t)]`。复云的负方位角标量模式不等于正m标量的复共轭；生产代码保留其独立源与独立径向响应，未擅自加c.c.或乘2。组合满足

`Phi(r,theta,phi+Omega_p dt,t+dt)=exp[−i(omega_c−Omega_p)dt] Phi(r,theta,phi,t)`。

所检验模式包括正负m_g及静态m_g=0，未发现用度规频率替代标量频率的相位错误。

## 视界通量对局部场的独立约束

在相同单位和未重标度BL径向函数约定下，

`F_H = 4 r+ (omega−omega_c)(omega−m Omega_H) |ZH|²`。

因此非静态模式的赤道近视界振幅为

`|ZH S_lm(pi/2)| / alpha³ = |S_lm(pi/2)|/alpha³ sqrt(|F_H/[4r+(omega−omega_c)(omega−mOmega_H)]|)`。

此式不经过空间Green累计积分或色标。由现有rp=41.6的scalar22视界通量−2.4787741721e−6，得到幅度 **0.2807800**。同m的ell4和ell6仅约0.0123584、0.0007933。即使允许任意相对ell相位，三角不等式仍给出下列非零下界。

| 轨道 | 单m=2视界幅度任意ell相位下界 | 保存场峰值半径上的角向RMS | 全场保存峰值 |
|---|---:|---:|---:|
| 41.6 | 0.26756865 | 0.28430435 | 0.34485982 |
| 41.8 | 0.26898524 | 0.28578670 | 0.34664805 |

这里“视界下界”取r趋于r+时的统一入射因子；RMS则是图5首个半径r=1.543027895上的实际复场离散Fourier计算。两者范围不同，未混作同一点等式。

在固定半径和theta下，Parseval恒等式给出角向平均 |Phi|²=sum_m|C_m|²，故 `max_phi|Phi| >= RMS_phi`。仅改变不同m的相位保持这个RMS不变；即使改变同m各ell相位，上述三角下界仍远大于0.04。因此“改Fourier相位即可把.345峰压为.04”与这些实际模式振幅不相容。此推论以现有源/通量与相同场定义为条件，不证明原图错误。

**色条上限不等于未截断最大场值。** 本地旧绘图把计算最大值自动设为色条上限；这与论文固定色限是否相同，需要单独核对。另一个子任务负责从原PDF检验色条饱和并按固定色限重画；本轮不重复作图，也不缩放或删除物理模式。

静态m_g=0的有效通量为零，不能由上述通量式反推出静态局部场。现有静态贡献在rp41.6的图5最大约0.01188，并不是.345近视界峰的主因。通量吻合本身也不能认证全部静态场。
