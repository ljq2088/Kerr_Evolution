# 论文细节与数学推导复核：本轮结论

日期：2026-09-17。对象：用户提供的 Dyson 等 arXiv:2501.09806v1（原PDF首页明确标注v1），以及后续独立对照 Li 等 arXiv:2507.02045v2。

**本轮确实定位了一处公开源公式的解析漏项，但当前协变代码已经包含它。故意按印刷式删去该项，反而使场图更不一致。当前显著场图残差尚不能宣布已修复，也不能归咎于已通过检验的源采样精度。**

## 1. 数学上已经证明的结果

### 1.1 Dyson 式 (17) 的 off-shell 项

对其式(14)定义的非密度算子 $Q=(\Box-\mu^2)\Phi$，正确的度规变分为

$$
\delta_gQ=-h^{ab}\nabla_a\nabla_b\Phi
-(\nabla_a\bar h^{ab})\nabla_b\Phi.
$$

其印刷式(17)额外的 $-hQ/2$ 不属于这个恒等式。但精确Kerr云满足 $Q=0$，故这一印刷差异不会改变后面的式(19)，也不能解释当前 Kerr 场差。直接数值改变度规、重新计算KG算子的独立有限变分检验支持上述恒等式，相对差小于 $9\times10^{-11}$。

### 1.2 Li 式 (66c) 的真实漏项

采用该文四标架和权重定义，令 $X=\Sigma\Delta h_{l_+l_-}$，应补在 $\Sigma\mathcal S$ 上的项是

$$
\boxed{\delta(\Sigma\mathcal S)=
\frac{X}{2\Sigma^2}
\left[\partial_r(\Delta\partial_rR_c)+\frac{K_c^2}{\Delta}R_c\right]S_c.}
$$

精确背景上等价于

$$
\delta(\Sigma\mathcal S)=
\frac{X(\mu^2r^2+\lambda_c)}{2\Sigma^2}\Phi_c,
\qquad\lambda_c=A_c+a^2\omega_c^2-2am_c\omega_c.
$$

它不正比KG残差，不能利用背景方程将其消掉。90个独立分量测试中，补回后全部系数与直接坐标收缩的差小于 $7.4\times10^{-16}$（以同点系数范数归一）。还有无需积分的反例：$a=\mu=\omega=m=0$，$\Phi=(r-1)\cos\theta$，$X=1$且其余独立输入为零，在$r=3$印刷源为零，正确源为$2\cos\theta/81$。

**这证明公开表达式不等价，不证明作者实际作图代码使用了错误表达式。** 当前生产代码直接计算 $h^{ab}\nabla_a\nabla_b\Phi_c$，已包含该项；没有为贴图删源。只在22通道故意删去该项后，相同9半径×72角的18模态场图幅度RMS偏差：

| 轨道 | 当前正确源 | 故意按印刷式遗漏22项 |
|---|---:|---:|
| $r_p=41.1M$ | 22.14% | 71.95% |
| $r_p=42.1M$ | 38.33% | 79.49% |

此为固定其余17通道的反事实实验，不是完整重跑作者程序。它否定“只这个漏项解释当前场图差”的假说。

## 4. 尚有影响的技术点及证据边界

1. **远区边界在质量阈值附近不均匀收敛。** 控制量含$k=\sqrt{\omega^2-\mu^2}$及库仑参数，而不是只看$|\omega|$。本例束缚22外转折点约5169.706M；此前公开四阶边界在4000M的控制不收敛，不能将它当作贴图修复。原Dyson论文在式(21)后已明确承认阈值前通量的小凹陷是数值伪影。因此该凹陷不应被强行拟合。
2. **作者显示的频率不是完整计算输入。** 把精确实部改成文中显示的0.296294，固定源控制会使$42.1M$的第二个径向谷从144.42M移至150.83M。它说明必须保存完整频率；没有证据证明作者实际进行了这种舍入，而且这样改后场图仍未对齐。
3. **未公开信息仍阻止逐模块最终归因。** 作者环境源的原始复数组、中间源图归一化、具体远边界参数、Imω处理顺序及图像模态筛选/作图脚本未完整公开。不能由一张颜色图反推唯一算法错误，也不能据当前源收敛就断言所有剩余差异均是原论文错误。
